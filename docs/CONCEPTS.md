# Агро-приложение «Свои Финансы»: расчёт норм кормления

## 1. Аудитория

| Сегмент | Описание | Потребности |
|---|---|---|
| ЛПХ (личные подсобные хозяйства) | 5–50 голов КРС/МРС, птица, свиньи | Простой расчёт суточных норм, список закупок, минимум терминов |
| Малые фермы (фермеры) | 50–500 голов, доение, откорм | Группировки по поголовью, годовая потребность в кормах, себестоимость |
| Зоотехники агрохолдингов | Несколько групп животных, рационы по phases | Таблицы норм (Рамзай/ОКС), контроль соответствия, экспорт |
| Ветфельдшеры / консультанты | Выездные расчёты рационов | Оффлайн-работа, PIN-доступ, шаблонные рационы |

## 2. Сценарии использования

1. **Утро фермера**: открыть приложение по PIN → на главном экране сводка: поголовье, суточная потребность в корме, прогноз расхода за месяц.
2. **Новое животное**: добавить телёнка/корову (вид, возраст, вес, продуктивность, условия содержания) → сервис рассчитывает суточную норму по видам кормов (концентраты, грубые, сочные, минеральные).
3. **Групповой рацион**: выбрать группу «Дойные коровы 6000 кг» → посмотреть таблицу норм и отклонения по отдельным животным.
4. **Планирование закупок**: экран «Годовая потребность» → итог по каждому корму в тоннах на год + стоимость по ценам из справочника → сформировать список закупки.
5. **Каталог кормов**: просмотр справочной таблицы питательности кормов (корм. единицы, переваримый протеин, сухое вещество).
6. **Профиль хозяйства**: название, регион, тип содержания (стойловое/пастбищное/смешанное) — влияет на коэффициенты рациона.

## 3. Концепции (выбранная — №1)

### Концепция 1 — «Кормовой калькулятор» (выбрана)
Фокус: быстрый расчёт норм и годовой потребности без бэкенда, оффлайн.
Ключевые функции:
1. Расчёт суточных норм кормления (КРС, МРС, свиньи, птица) по возрасту, весу, продуктивности и условиям содержания.
2. Годовая потребность хозяйства в кормах (кг/т) с оценкой стоимости.
3. Каталог кормов (таблица питательности).
4. Управление животными и группами (CRUD на тестовых данных).
5. Защита входа PIN-кодом.

### Концепция 2 — «Ферма+Финансы»
Фокус: себестоимость продукции.
1. Рационы как в концепции 1; 2. Учёт затрат кормов на 1 л молока / 1 кг привеса; 3. Бюджет закупки кормов по месяцам; 4. Отчёты по рентабельности; 5. Экспорт в CSV.

### Концепция 3 — «Полевой зоотехник»
Фокус: работа на выезде с оценкой качества кормов.
1. Фотофиксация силоса/сенажа с чек-листом качества; 2. Корректировка рациона по качеству корма; 3. Шаблоны рационов НСО/Рамзай; 4. Расчёт по нескольким хозяйствам; 5. Заметки и задачи для ветеринара.

## 4. Макеты экранов (реализовано 9)

1. **Вход** (`login`) — логотип, поля e-mail/пароль (любые данные принимаются — демо), кнопка «Войти».
2. **PIN-код** (`pin`) — 4 цифры, точки-индикаторы, клавиатура, «Забыли PIN?» (демо-PIN: 1234).
3. **Главный экран** (`home`) — приветствие, карточки-метрики (голова, суточный корм, годовой объём, стоимость), быстрые действия, последние животные.
4. **Список животных** (`animals`) — фильтр по видам, карточки с нормой.
5. **Карточка животного / детали расчёта** (`animal_detail`) — параметры, таблица суточных норм по видам кормов, доля в рационе.
6. **Форма добавления животного** (`add_animal`) — вид, возраст, вес, продуктивность, условия содержания.
7. **Каталог кормов** (`feed_catalog`) — таблица питательности (корм. ед., сырой протеин, СВ).
8. **Годовая потребность хозяйства** (`annual_need`) — итоги по кормам в т/год и ₽.
9. **Профиль** (`profile`) — хозяйство, настройки, смена PIN, выход.

Навигация: нижняя панель (Главная / Животные / Год / Каталог / Профиль) + push-экраны деталей и формы.

## 5. Модель расчёта (тестовые формулы)

Суточная норма кормовых единиц: `КЕ = базовая поддержка(вес) + продукция(молоко/привес/яйцо)`, коэф. условий содержания (стойловое 1.0, пастбищное 0.95, клеточное 1.05).
Нормы распределяются по видам кормов в % от КЕ: концентраты / грубые / сочные / минеральные — пропорции зависят от вида и продуктивности.
Годовая потребность = Σ суточных норм × 365, сгруппированная по видам кормов; стоимость = потребность × цена из каталога.

Подробности формул и пороговые значения закреплены unit-тестами (`app/test/`).
