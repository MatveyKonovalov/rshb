## ✨ Возможности

- 🐄 **Четыре вида животных:** КРС, МРС, свиньи и птица
- 📊 **Суточный рацион на голову** с разбивкой на грубые, сочные и концентраты
- 🧮 **Годовая потребность в кормах** в тоннах и в стоимости
- 🔍 **Каталог кормов** с поиском
- 🌗 **Светлая и тёмная тема** с переключением в профиле
- 🧪 **Покрытие тестами** расчётного модуля
- 🚫 **Без бэкенда:** все данные тестовые и хранятся в памяти

## 🧮 Модель расчёта

1. **Сухое вещество на голову** зависит от вида, веса, цели содержания и продуктивности.
2. **Молодняк** (до возрастного порога для вида) получает повышенную норму на рост, коэффициент **1,1**.
3. **Структура рациона** (грубые, сочные, концентраты) задаётся видом и условиями содержания.
4. **Масса корма** = сухое вещество / процент СВ корма.
5. **Годовая потребность:**

```
   Годовая потребность = масса корма × поголовье × 365 × (1 + потери)
```

   Потери: **5 %** в стойле, **8 %** на пастбище.

> ⚠️ **Важно.** Коэффициенты упрощённые и нужны для демонстрации логики. Для реальных рационов используйте официальные нормативы кормления и консультацию зоотехника.

## 🛡 Проверки и обработка ошибок

- Проверка поголовья, возраста, массы и продуктивности на допустимые значения.
- Если для группы не хватает подходящего корма или у корма некорректная доля сухого вещества или цена, приложение показывает предупреждение.
- Такая группа **не входит в итог** годовой потребности, поэтому неполный рацион не выглядит законченным расчётом.
