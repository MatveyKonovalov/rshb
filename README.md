# АгроКорм: расчёт норм кормления

Сервис расчёта норм кормления КРС, МРС, свиней и птицы с учётом возраста, веса, продуктивности и условий содержания. Считает суточные рационы и годовую потребность хозяйства в кормах. Приложение работает без бэкенда, данные тестовые.

## Структура

```
agrokorm/
├── lib/
│   ├── main.dart                 точка входа и маршруты
│   ├── routes.dart               имена маршрутов
│   ├── models/models.dart        виды, цели, корма, группы животных
│   ├── data/mock_data.dart       тестовые группы и каталог кормов
│   ├── services/feed_calculator.dart   расчёт рационов и годовой потребности
│   ├── widgets/common.dart       общие виджеты и форматирование чисел
│   └── screens/                  экраны приложения
├── test/feed_calculator_test.dart   тесты расчётного модуля
├── docs/concepts.md              аудитория, сценарии, концепции
├── mockups/mockups.html          макеты восьми экранов (открыть в браузере)
├── setup.sh                      создание платформ, проверка и тесты
├── pubspec.yaml
└── analysis_options.yaml
```

## Экраны

1. Вход
2. PIN-код (тестовый: `1234`)
3. Главная: сводка по поголовью, годовому объёму кормов и суточным затратам
4. Стадо: список групп с фильтром по виду
5. Детали группы: параметры и суточный рацион на голову
6. Каталог кормов: таблица с поиском
7. Годовая потребность: объёмы в тоннах и стоимость
8. Профиль: данные хозяйства, уведомления, выход

## Запуск

Нужен установленный Flutter 3.x (Dart 3). Из папки проекта:

```bash
./setup.sh          # один раз: создаёт платформы, загружает пакеты, запускает тесты
flutter run -d linux
```

Для Chrome: `flutter run -d chrome`.

## Модель расчёта

- Сухое вещество на голову зависит от вида, веса, цели и продуктивности.
- Молодняк (до порога возраста вида) получает повышенную норму на рост, коэффициент 1,1.
- Структура рациона (грубые, сочные, концентраты) зависит от вида и условий содержания.
- Масса корма = сухое вещество / процент СВ корма.
- Годовая потребность = масса корма × поголовье × 365 × (1 + потери). Потери 5% в стойле, 8% на пастбище.

Коэффициенты упрощённые и предназначены для демонстрации логики. Для реальных рационов нужны официальные нормативы кормления и проверка зоотехником.

## Проверки и обработка ошибок

- Расчёт проверяет поголовье, возраст, массу и продуктивность на допустимые значения.
- Если для группы не хватает подходящего корма или у корма некорректная доля сухого вещества/цена, приложение показывает предупреждение. Такая группа не включается в итог годовой потребности, чтобы неполный рацион не выглядел завершённым расчётом.
- Тесты покрывают все четыре вида животных, сумму долей рациона, годовую формулу с потерями, отсутствие кормов и некорректные входные данные.
- Коэффициенты остаются демонстрационными. Они не являются официальными зоотехническими нормативами и не предназначены для назначения реального рациона.

## Ограничения

- Данные хранятся только в памяти и после перезапуска сбрасываются.
- Добавление и редактирование групп и кормов не реализовано, список задан в `lib/data/mock_data.dart`.
- Макеты показывают условные значения.

## Тема оформления

Тема задаётся в `lib/theme/app_theme.dart`: светлая и тёмная палитра из одного акцентного цвета. Переключение (Авто, Светлая, Тёмная) находится в профиле и сохраняется на время работы приложения.
